# DeepSeek V4 Flash Local Desktop

**DeepSeek V4 Flash Flash 0731** runs **deepseek v4 flash** (0731) on your machine. **Free download**, no API key, no cloud. **GGUF** + **ollama**, CUDA or CPU. **Deepseek v4 flash vs deepseek-v4-pro-0813** — Flash is the fast MoE (236B / 37B active), 1M context, compressed sparse attention.


**Requirements?**

**Is it free?**
Yes. MIT client, local weights, no subscription.
